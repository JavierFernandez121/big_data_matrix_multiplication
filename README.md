# Matrix Multiplication — Big Data Individual Assignments

Empirical study of the performance and scalability of dense matrix
multiplication, developed in four assignments for the Big Data course
(Grado en Ciencia e Ingeniería de Datos, ULPGC, 2026–2027).

| Assignment | Topic | Folder |
|---|---|---|
| 1 | Basic matrix multiplication in Python, Java and C | [`assignment1/`](assignment1/) |
| 2 | Optimised approaches and sparse matrices | *(to do)* |
| 3 | Parallel matrix multiplication | *(to do)* |
| 4 | Distributed matrix multiplication | *(to do)* |

Each assignment folder is self-contained and has its own README with the exact
commands to reproduce the experiments.

## Requirements

- Python 3.10+ with the packages in `requirements.txt` (`pip install -r requirements.txt`)
- Java JDK 17+ (`javac` and `java` on the PATH)
- GCC (on Windows, e.g. WinLibs/MinGW-w64)
